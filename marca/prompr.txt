# ETAPA 1

Estude primeiro os padrões fonéticos das maiores marcas do mundo.

Analise centenas de marcas de sucesso.

Descubra padrões como:

• quantidade ideal de sílabas
• alternância entre vogais e consoantes
• sons mais memoráveis
• facilidade de escrita
• facilidade de pronúncia
• força visual
• neutralidade internacional

NÃO copie nenhuma marca.

Utilize apenas os padrões.

# MODO DE EXECUÇÃO (OBRIGATÓRIO)

Este projeto pode envolver dezenas de milhares de candidatos e milhares de verificações.

NÃO tente manter todas as informações apenas no contexto da conversa.

Utilize o sistema de arquivos local como armazenamento intermediário.

Todo o processamento deve ser realizado em etapas independentes.

Após concluir cada etapa:

• salvar os arquivos
• registrar um checkpoint
• liberar memória
• iniciar a próxima etapa utilizando apenas os arquivos produzidos anteriormente

Nunca reiniciar o projeto caso uma etapa falhe.

Sempre continuar a partir do último checkpoint disponível.

Criar automaticamente a seguinte estrutura:

Projeto_Naming_Global/

    00_Config/

    01_Geracao/

    02_Filtros/

    03_Verificacao/

    04_Ranking/

    05_Finalistas/

    06_Relatorios/

    checkpoints/

Cada etapa deve produzir arquivos próprios.
