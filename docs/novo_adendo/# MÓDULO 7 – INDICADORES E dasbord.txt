# MÓDULO 7 – MOTOR DE INDICADORES E DASHBOARDS

**Documento:** MID-001

**Versão:** 1.0

**Status:** Em Desenvolvimento

---

# 1. Objetivo

O Motor de Indicadores e Dashboards é responsável por consolidar, calcular e disponibilizar todos os indicadores da plataforma para profissionais de saúde e pacientes.

Este módulo **não executa decisões clínicas**, **não altera prescrições** e **não modifica dados**.

Sua função é transformar dados clínicos, nutricionais e comportamentais em informações visuais para apoio à tomada de decisão.

---

# 2. Responsabilidades

O módulo deverá:

* Consolidar indicadores.
* Calcular indicadores derivados.
* Gerar dashboards.
* Gerar gráficos.
* Gerar comparativos históricos.
* Gerar tendências.
* Gerar alertas visuais.
* Disponibilizar indicadores para outros módulos.

---

# 3. Fontes de Dados

O módulo poderá consumir informações provenientes de:

* Módulo Clínico.
* Motor Metabólico.
* Motor Adaptativo.
* Motor de Qualidade dos Dados.
* Motor de Exceções.
* Banco Histórico.
* Aplicativo do Paciente.
* Smartwatch.
* Exames laboratoriais.
* Bioimpedância.
* DEXA.
* Integrações futuras.

# 15. Dashboard do Paciente

O paciente deverá visualizar apenas:

* Evolução do peso.
* Evolução corporal.
* Cumprimento das metas.
* Alimentação.
* Exercícios.
* Sono.
* Hidratação.
* Próximas metas.
* Mensagens do profissional.

O paciente **não visualizará**:

* Logs.
* Auditoria.
* Sugestões rejeitadas.
* Scores internos.
* Regras do Motor Adaptativo.
* Informações destinadas exclusivamente ao profissional.

---

# 16. Atualização dos Indicadores

Cada indicador deverá possuir sua própria política de atualização.

Exemplos:

| Indicador           | Atualização                       |
| ------------------- | --------------------------------- |
| Peso                | Novo registro                     |
| TMB                 | Novo cálculo metabólico           |
| TDEE                | Novo cálculo ou recalibração      |
| Sono                | Sincronização diária              |
| Passos              | Sincronização diária              |
| Exames              | Inclusão de novo exame            |
| Qualidade dos Dados | Após qualquer alteração relevante |

* Valores utilizados no cálculo.

---

# 19. Critérios de Aceitação

O módulo será considerado implementado quando:

* Todos os indicadores forem calculados de forma reproduzível.
* Os dashboards forem separados por perfil de usuário.
* Os indicadores possuírem histórico e auditoria.
* Nenhum indicador modificar dados clínicos.
* Os gráficos apresentarem evolução temporal e comparação entre períodos.
* O sistema permitir adicionar novos indicadores sem alterar a arquitetura existente.

---

# 20. Requisitos para IA Implementadora

### Arquitetura

Implementar um **Catálogo de Indicadores**, onde cada indicador seja tratado como uma entidade configurável, contendo:

* Identificador único.
* Nome.
* Categoria.
* Unidade.
* Fórmula de cálculo (quando aplicável).
* Fonte dos dados.
* Frequência de atualização.
* Permissões de visualização.
* Dependências.
* Versão.

Os dashboards devem consumir exclusivamente esse catálogo, evitando cálculos diretamente na interface.

### Princípios

* Nenhum cálculo deverá ser implementado na camada de apresentação (frontend).
* Todos os indicadores devem ser reutilizáveis por APIs, relatórios e dashboards.
* Os componentes gráficos devem ser configuráveis (linhas, barras, radar, velocímetro, tabelas e heatmaps).
* O controle de acesso deve garantir que cada perfil visualize apenas os indicadores autorizados.
* Toda informação exibida deve ser rastreável até sua origem, permitindo auditoria completa.

---

## Recomendação de evolução (V2)

Para diferenciar a plataforma, recomendo que o Motor de Indicadores incorpore futuramente um conceito de **"Indicadores Compostos"**, calculados a partir da combinação de múltiplas métricas. Exemplos:

* **Índice de Adesão ao Tratamento** (alimentação + exercícios + sono + hidratação).
* **Índice de Risco Metabólico** (circunferência abdominal + HbA1c + perfil lipídico + pressão arterial + IMC).
* **Índice de Recuperação** (sono + HRV + frequência cardíaca de repouso + carga de treino).
* **Índice de Qualidade Nutricional** (macronutrientes + fibras + ingestão hídrica + regularidade alimentar).

Esses indicadores devem ser configuráveis, versionados e sempre acompanhados da fórmula de composição e dos dados utilizados, preservando a transparência e a rastreabilidade da plataforma.
