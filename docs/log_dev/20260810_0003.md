## Backlog registrado — "Motor de Sono Avançado" (não implementado na v1.0)

Descrição literal fornecida pelo fundador, preservada na íntegra para
referência futura:

> Incluir na anamnese perguntas sobre horário normal de deitar e levantar.
> Gravar isso no perfil do usuário com telas de manutenção no app e no
> painel web. Criar um parâmetro global "X horas" editável pelo admin. O
> sistema contabilizará o início da noite de sono a partir do [horário de
> dormir do usuário menos X horas], abandonando a heurística fixa das 15h.

**Onde isso se conecta ao código atual**: substituiria
`HealthSyncService._dataDoSonoLocal` (a heurística fixa ">=15h conta para o
dia seguinte", introduzida no RELATÓRIO 20260810/0002) por um cálculo
dependente do perfil do usuário (`horario_dormir_habitual - X horas`, com
`X` configurável globalmente por admin). Motivo de não entrar na v1.0
(decisão do fundador, não técnica): exige anamnese nova, telas de
manutenção no app E no painel web, e um parâmetro admin global — escopo de
produto maior que o ajuste pontual desta tarefa. A heurística fixa das 15h
continua valendo até esta ideia ser priorizada.
