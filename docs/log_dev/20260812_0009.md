# 20260812_0009 — Tela de simulação do Motor Metabólico no Painel Web

Log de Máquina (Regra 10.3 — append-only). Pedido direto de acompanhamento
do N07 (RELATÓRIO 20260812_0008): expor a RPC `calcular_motor_metabolico`
numa tela do Painel Web, que até então só tinha sido verificada por script.

## O que foi feito

- Novo `MotorMetabolicoCard.tsx` (`web_painel/src/features/dashboard/
  components/`): chama `calcular_motor_metabolico` para o paciente aberto
  e mostra TMB / Gasto Sedentário / Gasto de Atividade / TDEE em destaque,
  TEF isolado (com o texto explícito de que NÃO está somado ao TDEE — o
  mesmo anti double-count que a RPC já implementa, replicado na
  apresentação para não confundir o profissional), a fórmula usada
  (badge colorido: Katch-McArdle/Mifflin-St Jeor/Dados insuficientes), os
  insumos usados (idade/sexo/altura/peso/massa magra) e os avisos de dado
  faltante traduzidos para frases legíveis.
- Montado em `PatientDetails.tsx`, logo abaixo do cabeçalho — mesma tela
  onde o profissional já edita sexo biológico e registra telemetria
  manual (RELATÓRIO 20260812_0008).
- Recalcula automaticamente (sem precisar apertar nada) quando: a tela
  abre, o profissional salva uma medição pelo `InserirMedicaoModal`, ou
  altera o sexo biológico — os três eventos que mudam o resultado da RPC.
  Um botão "Recalcular" manual também existe, para o caso de o dado ter
  mudado por outra via (ex.: o próprio paciente atualizou o peso pelo
  app).
- Puramente uma simulação/visualização: não grava nada no banco.

## Verificação

- `tsc -b`/`npm run build`/`npm run lint`: limpos (só as 2 warnings
  pré-existentes de `scripts/seed_taco_completa.ts`). Sem suíte de testes

  mesma lacuna já registrada em tarefas anteriores desta sessão); a RPC
  em si já foi verificada exaustivamente com 3 casos reais e conferência
  manual da matemática no RELATÓRIO 20260812_0008 — esta tarefa só
  consome esse contrato já testado, não reimplementa nenhum cálculo.
- Nenhuma migration nova, nenhuma mudança no App Flutter.
