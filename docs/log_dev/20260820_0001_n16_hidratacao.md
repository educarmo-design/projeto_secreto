## Decisões de arquitetura

- **Sem tabela nova para os registros**: `coleta_diaria` (F34,
  `20260730130000_coleta_diaria_eav.sql`) já é o EAV genérico de
  leituras frequentes, com RLS/GRANT já cobrindo a tabela inteira —
  uma linha por registro de água, `atributo = 'agua_ml'`,
  `valor_numerico` = ml, `unidade = 'ml'`, `origem = 'manual'` (nunca
  há OCR/wearable de hidratação, o usuário sempre confirma a
  quantidade). Mesmo padrão que `gravarRefeicao` já usa pra
  `atributo = 'refeicao'`.
- **Tamanho do copo é dado de PERFIL, não métrica diária**: nova coluna
  `perfis_usuarios.tamanho_copo_ml` (int, default 200) — mesmo
  raciocínio de `altura_cm` (muda raramente, não é uma leitura do dia).
  Faixa plausível (50–1000 ml) validada só client-side, sem CHECK no
  banco — mesmo padrão de `altura_cm` (não é dado regulatório).
- **Histórico agrupado em Dart, não RPC**: `coleta_diaria` tem várias
  linhas por dia (um registro por toque); o volume (poucos
  registros/dia, 7 dias) não justifica uma RPC só pra somar por dia —
  mesmo espírito de `HealthSyncService._mesclarPorDia`.
- **Widget no dashboard reaproveita a "Fábrica de Widgets
  Configuráveis" já existente** (`DashboardWidgetId`/
  `DashboardWidgetFactory`, sistema local via `flutter_secure_storage`
  — não é o `catalogo_widgets` do banco, esse é N21, ainda não
  construído): novo 9º id `hidratacao`, adicionado no FIM do enum
  (`WidgetLayoutModel.fromJson` já mescla ids novos no fim da ordem
  salva do usuário — confirmado lendo o código, não presumido).

## Como o fundador testa (quando o celular estiver livre)

1. Abrir o app → aba Dashboard → tocar no ícone de copo d'água na
   AppBar (ou no card "Hidratação", se estiver visível no painel).
2. Tocar "+1 copo (200 ml)" duas vezes → "Hoje: 400 ml" no topo da
   tela, e o histórico mostra "hoje: 400 ml" na lista.
3. Voltar pro Dashboard → o card de Hidratação mostra "Hoje: 400 ml"
   também (recarregado ao voltar da tela).
4. Editar "Tamanho do copo" pra 350 → salvar → o botão "+1 copo" passa
   a mostrar "(350 ml)".
